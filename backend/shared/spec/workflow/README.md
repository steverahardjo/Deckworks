# Workflow catalog

Workflow specs select the operating mode. The detailed operating instructions
remain in `backend/shared/skills/SKILL.md` so the MCP does not repeat them.

| Workflow | File | Purpose |
| --- | --- | --- |
| `create` | `create.md` | Build a new narrative and draft. |
| `edit` | `edit.md` | Make a focused change to an existing deck. |
| `review` | `review.md` | Inspect quality and rendering readiness. |
| `export` | `export.md` | Validate and produce an output artifact. |
| `research` | `research.md` | Build a scratchpad-led evidence chain and resolve material source gaps. |
| `accounting` | `accounting.md` | Reconcile financial and management reporting. |
| `consultant` | `consultant.md` | Structure executive problem solving and recommendations. |
| `startup` | `startup.md` | Build metric-led pitch and product narratives. |
