# Look catalog

Look specs are discovered from this directory at runtime. Each look owns its
palette, font stack, layout grid, density ceiling, and the rendered components
appropriate for that visual system.

| Look | File | Purpose |
| --- | --- | --- |
| `minimal` | `minimal.md` | Monochrome restraint and space-led hierarchy. |
| `consulting` | `consulting.md` | Assertion-led default with one exhibit per slide. |
| `dark` | `dark.md` | Dark on-screen stage with a single accent. |
| `editorial` | `editorial.md` | Warm, long-form narrative pacing. |
| `academic` | `academic.md` | Beamer-inspired, evidence-first academic communication without native LaTeX rendering. |
| `startup` | `startup.md` | Metric-forward product and pitch storytelling. |
