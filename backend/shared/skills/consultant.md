# Consultant

Use for executive problem solving, strategy recommendations, operating-model
reviews, due diligence, and decision memos presented as slides.

## Narrative method

Frame the work as situation → complication → answer. Write action titles that
state the implication, then use one decisive exhibit or structured comparison to
prove each title. Keep hypotheses, evidence, assumptions, and recommendations
visibly distinct.

## Setup and gate

At setup, confirm the client context, decision maker, decision date, and
required house style. At the narrative gate, show the issue tree or storyline
before building slides. Use `chart`, `table`, `callout`, and `divider` only when
each has a reasoning job; never fill a slide with generic consulting ornament.

## Evidence

Record sources, calculations, and open questions in `scratchpad.md` and the
selected look in `deck-profile.md`.

## Implement

Follow the `create` gate structure, then load the `build` subskill for the
stylesheet, layout, and Python slide-HTML rules.
