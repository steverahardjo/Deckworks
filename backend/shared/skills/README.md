# Deckworks skills

`SKILL.md` is a thin router: it selects exactly one workflow subskill and one
look, then applies the universal operating contract. Load only the subskill you
route to. The MCP discovers every Markdown file here at runtime.

| Skill | File | Purpose |
| --- | --- | --- |
| `SKILL` | `SKILL.md` | Thin router: route one workflow, load one look, apply the universal contract. |
| `build` | `build.md` | Shared authoring contract: stylesheet, layout, implementation sequence, Python slide-HTML rule. |
| `create` | `create.md` | Build a new narrative and draft with a narrative approval gate. |
| `edit` | `edit.md` | Make a focused change to an existing deck. |
| `review` | `review.md` | Inspect layout, density, assets, and rendering issues. |
| `research` | `research.md` | Build a traceable evidence ledger and synthesize supported claims. |
| `accounting` | `accounting.md` | Reconcile financial and management reporting. |
| `consultant` | `consultant.md` | Structure executive problem solving and recommendations. |
| `startup` | `startup.md` | Build metric-led pitch and product narratives. |
| `export` | `export.md` | Validate and produce an output artifact. |
| `data-analysis` | `data-analysis.md` | Analyze datasets and create renderer-safe chart assets. |
